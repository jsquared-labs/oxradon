radon’s code metrics,
without the wait.

A Rust port of radon, the code-metrics tool for Python. It takes radon’s commands and flags and prints the same output.

$ radon cc -s corpus/0.0 s
0 / 3,824 files ✓
$ oxradon cc -s corpus/0 ms
0 / 3,824 files ✓

0× faster

Real time, not sped up. 3,824 files from eight popular packages (Django, SymPy, SQLAlchemy, Pydantic, Rich, Black, FastAPI and httpx) on an Apple M5 with 10 cores and a warm file cache, measured 15 November 2026. Finish times are the best of several runs; the bars move at an even rate in between. Reproduce it

Swap it in

$ uv tool install oxradon

Or pipx install oxradon, or pip install oxradon. Prebuilt for Linux (x86-64 and ARM, including Alpine) and macOS (Apple silicon and Intel), so no Rust is needed. To try it once, run uvx oxradon cc -s src/. With Rust, cargo install oxradon builds it from source.

Then run oxradon wherever you ran radon. The two can be installed side by side.

$ oxradon cc -s -a src/

It reads the same configuration files (radon.cfg, setup.cfg, pyproject.toml, ~/.radon.cfg, RADONCFG) and needs no Python to run. It’s also a Rust library.

radon’s quirks are reproduced too. Where the two differ, mostly where radon would crash or stop, COMPATIBILITY.md lists every case.

When to keep using radon

Stay with radon if you:

  • analyze Jupyter notebooks;
  • need cc --xml, --md or --codeclimate;
  • import radon from Python;
  • work on Windows.

Why the gap is so uneven

cc and hal gain from Ruff’s compiled parser and from using every core. raw and mi gain much more. For each logical line, radon re-tokenizes a growing buffer, which is quadratic in long statements. oxradon gets the same answers in one pass, so most of that gap is the algorithm, not Rust.

oxradon ports radon’s algorithms and output formats. radon was written by Michele Lacchia and its contributors; oxradon is independent of them and not affiliated. Parsing uses Ruff’s Python parser.
